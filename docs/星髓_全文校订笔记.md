# 《星髓》全文校订笔记

> 依据用户提供的 EPUB 逐章通读整理，只记录情节结构与游戏改编要点，不摘录原文长段落。

## 第一部：船（序章—第五章）

- 大船本身拥有第一人称意识，但无法向进入船体的人类发声；它来自银河系之外，是约二十个地球质量、由类木行星改造的古老巨舰，拥有行星级喷嘴、燃料海、超纤维船壳与复杂空港。
- 人类发现并占领大船后，由首领船长建立环银河商业航程，接纳大量外星物种居住；船长阶层长期管理船内社会，人类借基因与生物陶瓷技术接近永生。
- 浣生是擅长外星文化的资深船长，年轻时与拒绝永生的翡尼克斯人相恋；翡尼克斯叛乱造成永久死亡，使她走上船长道路并形成对职责、异族与秩序的复杂态度。
- 迈尔辛是务实而傲慢的副首领。她早年设计船壳维修义务，后来促成了雷莫拉文化：雷莫拉长期生活在防护服中，适应辐射、主动控制突变并负责船外维修，与船长体制矛盾深刻。
- 帕米尔是被革职后隐居的前船长，曾以激进但有效的方式处理两个盖亚生命体冲突，与浣生互相信任。
- 首领以黑色等级阿尔法协议召集数十位精英船长潜伏集结。她公布：五十三年前的彗星撞击波暴露了空心内核；内核中悬浮着一颗火星大小、质量极高、有氧气和水的金属行星，并命名为“髓星”。
- 游戏校订：删除“弥舟、记忆污染、髓瓷复生、零号灯塔”等伪原著设定；保留大船内部海洋作为局部生态舱，但将任务改为首领主持的秘密髓星远征，角色改围绕浣生、迈尔辛、帕米尔及雷莫拉展开。

## 第二部：髓星（第六—二十七章）

- 精英船长从燃料罐下方的秘密基地进入髓星。空腔中的蓝白支撑力场会侵蚀生命和机器，船长依靠超纤维桥登陆；髓星拥有熔铁河、永昼、极端地震，以及依靠灾难快速繁衍的黑色生态系统。
- “事变”突然使上下支撑力场合并，摧毁全部人工智能、交通工具、通信与桥梁。浣生的小队在坠机后用永生基因重塑身体，徒步近四年回到营地；首领始终没有救援，幸存船长开始怀疑自己遭到抛弃。
- 支撑力场减弱后髓星缓慢膨胀，预计约五千年后接近空腔壁。船长从零重建工具、工业和城市，将“等待膨胀后造桥回船”确立为长期目标。
- 船长们利用锤翅生物唾液恢复生育能力。迈尔辛生下提欧，浣生和笛雾生下洛克。提欧宣称自己能接触建造者灵魂，认为髓星后代是建造者重生，船长只是暂居的客人。
- 提欧与大量后代出走成为“违望者”；迈尔辛领导“忠诚者”。两边在数千年中分别形成游牧神权文明和工业化造桥文明，人口、资源、技术与宗教冲突不断升级。
- 熔铁中发现的大船形记忆库起初为空。后来可用记忆库展示“荒凉”入侵、建造者触发事变的影像，似乎印证提欧的信仰；违望者将空记忆库解释为建造者灵魂已经转生。
- 违望者学者“美德”叛逃，发现髓星内部还有约五十公里宽的隐藏结构。迈尔辛秘密保留其大脑、重建身体，并与他合作制造穿越弱化支撑力场的炮弹车。
- 四千多年后，迈尔辛强迫浣生一起射入旧桥，成功返回大船。大船依然繁荣，首领完全不知道髓星任务；她们才意识到远征命令和首领影像都是伪造。
- 幕后者是笛雾。他早在成为船长前就发现、登陆髓星，观察其周期两万年；他伪造任务、记忆库与建造者神话，诱使精英重建文明，并通过大量后代塑造违望者军队，真正野心是夺取整艘大船。
- 笛雾袭击浣生与迈尔辛，洛克赶到并杀死父亲。提欧承认早已知道骗局，却把笛雾视作建造者的工具；他俘获濒死的迈尔辛，只保留其头脑。
- 游戏校订：五关可依次表现登陆基地、永昼熔铁荒原、事变坠落、忠诚者大桥和离奇族栖息地反转；记忆碎片必须分为“伪造档案”与“可验证证据”，玩家不应通过收集记忆获得超自然真相，而应逐步识破笛雾的操纵。

## 第三部：首领的椅子（第二十八—四十四章）

- 首领长期搜寻失踪船长无果，对外谎称他们死于秘密任务。帕米尔获赦回归，受命调查浣生与迈尔辛突然出现的全息通讯。
- 帕米尔在离奇族废弃栖息地找到浣生的银表，又通过中微子流发现核心异常。他监督挖掘秘道一百多年，最终撞见从髓星上来的洛克。
- 提欧率数百万违望者沿新打通的隧道登船。迈尔辛在年度宴会割下首领的头，利用旧权限瘫痪安保系统，夺取大船，自任首领、任命提欧为首席。
- 帕米尔从液氢燃料海中找回浣生的头与手臂，使她重生。洛克承认他故意留下银表线索，希望有人救回母亲。
- 浣生识破更深一层：提欧早已知道笛雾伪造神话，却仍然真心相信建造者；他把笛雾视作传递真相的“容器”。提欧掌握髓星深处的物质—反物质能量源。
- 帕米尔依据大船法律成为临时首领，联合雷莫拉人发动抵抗。局部破坏升级成内战。

## 第四部：“荒凉”（第四十五—五十三章）

- 违望者屠杀并占领雷莫拉城市，雷莫拉破坏主引擎和防护盾；天体碎片不断撞击失去保护的大船。
- 浣生与洛克潜回髓星，邀请迈尔辛会面。浣生提出新假说：大船并非由气态巨行星改造，而可能由早期宇宙的非有机建造者从髓星核心向外逐层制造。
- 髓星可能是有机生命的早期实验场；量子支撑力场则是监狱墙。被囚禁的“荒凉”比建造者更古老，能通过梦与指令影响笛雾、提欧和其他人。
- 提欧借脊柱绕过迈尔辛，控制全部引擎，要让大船擦过红巨星再坠入伴生黑洞。迈尔辛终于承认自己一直被儿子利用，并以地震阵列摧毁大桥、以生命拖住提欧。
- 帕米尔用液氢洪流威胁髓星，浣生明确拒绝屠杀无辜；他们在洪水落下前关泵，救下髓星居民。

## 第五部：建造者与结语

- 荒凉控制引擎把大船拖向红巨星。雷莫拉人、哈鲁萨鲁、人类工程师、人工智能和约百个物种协同破坏阀门、燃料管道、磁瓶与喷嘴。
- 大船的第一人称意识终于主动帮助船员：提示正确阀门和故障时机。一次月球级铁镍撞击使航线偏离红巨星；随后的黑洞引力将大船送向星系间的黑暗。
- 大船将离开银河，未来驶向室女座星团。旧首领复生，但权力受制；浣生成为首席，帕米尔拒绝该职位。
- 浣生、洛克与书记官继续研究建造者。洛克提出更宏大的假说：若船壳只是多层结构之一，建造者的工程也许延伸到整个宇宙。
- 通往髓星的豁口被重新浇铸超纤维封闭，只留下隐蔽安全眼。荒凉仍未被理解，也未被消灭。
- 游戏校订：正史结局必须是百族共同关停引擎、重封髓星、浣生任首席、大船转向室女座；“释放记忆”一类旧结局与原著无关，已删除。
