# 《潮声之下》对标原神 · 差距分析与改进计划

> 基准：原神（移动端体验为准）。对象：潮声之下 v28（桌面版）/ v28m（手机版）。
> 结论先行：我们的**战斗手感基建、关卡内容量、经济装备**已接近移动端原神的骨架；
> 真正的差距集中在五件事——**元素战斗深度、长线养成、终局玩法、世界探索感、剧情演出**。
> 本计划按"性价比"排四期，每项都映射到现有代码的具体改造点，均可离线单文件实现。

---

## 一、现状盘点（我们已有、且不输移动端原神的部分）

| 系统 | 现状 |
|---|---|
| 内容量 | 五部 100 关（船/髓星/首领的椅子/荒凉/建造者），每 4 关阶段巨兽 |
| 武器/技能 | 三角色专属武器（远程/近战/范围）+ 每角色 3 主动技，蓄力重击、处决、完美闪避 |
| 经济装备 | 局内金币 + 6 槽装备 24 件（含弹道/贯穿/制导/元素变奏/爆裂等机制装） |
| 元素反应 | 潮/蚀/震 3 元素 × 锈蚀/涌爆/碎甲 3 反应（附着 6s，BOSS 同享） |
| 探索基建 | 攀爬/登顶、水下推进器、传送塔、扫描塔、存档码头、小地图 |
| 巨兽战 | 阶段机制/狂化/运镜/韧性破韧处决，8 种 BOSS |
| 表现 | 真 HDR 后处理（Bloom/暗角/色差）、出场运镜、伤害飘字、受击方向指示 |
| 移动端 | 王者式键位（扇形技能+冷却扇形+图标贴图）、自动普攻、性能降档、横屏提示 |
| 元游戏 | 主线剧情档 100 章、每日挑战、成就 20、休息站永久升级、商栈、路线事件 |

## 二、差距对比（维度 / 原神做法 / 我们的差距 / 评级）

| # | 维度 | 原神 | 我们的差距 | 评级 |
|---|---|---|---|---|
| 1 | **战斗深度** | 7 元素互相反应、绽放/激化等 15+ 反应、下落攻击、元素护盾克制 | 只有 3 元素 3 反应且单角色单元素难以触发；无下落攻击；敌人无元素盾 | ★★★ 最大差距 |
| 2 | **长线养成** | 角色等级/突破/天赋/命座，圣遗物随机词条刷取 | 通关即毕业：无角色成长线，装备全固定词条，打完 100 关没有目标 | ★★★ |
| 3 | **终局玩法** | 深境螺旋（限时分层评星）、幻想真境剧诗 | 只有无尽波次和每日挑战，没有"打得更深更强"的结构化终局 | ★★☆ |
| 4 | **世界探索感** | 无缝大世界、宝箱/解谜/神瞳/隐藏任务密度 | 关卡制竞技场，兴趣点只有样本+塔+热泉，"探索"=跑图打怪 | ★★☆ |
| 5 | **剧情演出** | 过场动画、配音、对话分支、角色语音 | 纯文字页+通讯条，无立绘/打字机/分支演出（分支只影响数值） | ★★☆ |
| 6 | **音频** | 分层动态音乐、环境声、全配音 | 程序化音效，无音乐层、无环境底噪 | ★☆ |
| 7 | **视觉氛围** | 卡通渲染、昼夜、天气、水面 | 固定雾色氛围，无昼夜/天气循环，水体表现弱 | ★☆ |
| 8 | **操作外设** | 手柄/键鼠/触屏三端 | 仅键鼠+触屏，无手柄（Gamepad API） | ★ |
| 9 | **战斗反馈** | 命顿/镜头/音效层次 | 已有 hit-stop/震屏/飘字——差距小 | ✓ 基本持平 |
| 10 | **移动端适配** | —— | 我们的王者式键位+自动普攻反而更贴合国内手游习惯 | ✓ 领先项 |

## 三、改进计划（四期，按性价比排序）

### 第一期 · 战斗深度【已完成 v30】（核心差距，让"原神味"立起来）
1. **元素扩展 3→6**（工作量 L）
   新增：声波(风)/霜寒(冰)/雷磁(雷)。装备新增"元素注入器"系列（武器附魔：把任意武器弹道改为指定元素）——这同时解决"单角色单元素打不出反应"的问题。
   新反应：风+任意=扩散（AOE 传播附着）、冰+火/雷=融化/超导、雷+水=感电（跳跃传导）。反应表接 `applyElementHit`，附着时长沿用 6s。
2. **下落攻击 + 空中攻击**（M）
   推进器/跳跃滞空时按攻击 → 下坠砸地（范围伤害+击退，落点预警圈复用铁雨表现）。近战滞空挥击复用 meleeCone。
3. **敌人元素护盾**（M）
   精英/BOSS 加元素盾条（第一血条）：用克制元素打盾 3 倍速破盾，同/弱元素 0.5 倍——复用韧性条 UI 位置。
4. **近战连击段数**（S）
   迈尔辛普攻三段（伤害递增 1.0/1.1/1.4，第三段小击飞），段间 0.9s 内衔接。

**验收**：注入器装备后，任意角色可在 10 秒内打出 2 种新反应；带盾精英用克制元素破盾时间 ≤ 8s。

### 第二期 · 养成与终局【已完成 v31】（把"打完 100 关"变成"刷 100 关"）
5. **角色等级/突破**（L）
   局内击杀掉"髓能结晶"；主页新增角色页：等级(1-60)提升基础属性，每 20 级突破材料关卡（专用试炼节点）。
6. **天赋升级**（M）
   三主动技各 1-5 级：数值按级成长，材料=结晶+船币。技能卡 UI 显示等级。
7. **"深潜遗章"圣遗物系统**（L）
   5 槽（花/羽/杯/冠/环→我们的 潜服/鳍片/镜片/核心/舱徽），主词条固定+4 副词条随机（伤害/暴击/生命/冷却/金币加成…），每日挑战与深井掉落，三档品质。复用装备背包 UI，加"词缀重铸"。
8. **"回响深井"终局**（M）
   12 层限时挑战（每层波次+词缀，如"蚀元素伤害+50%/治疗-50%"），三星评星（时间/存活/连杀），星数解锁遗章掉落加成。复用无尽波次框架+词缀系统。

**验收**：从 0 练一个角色到 60 级 + 5 件遗章约 6-8 小时内容；深井 12 层通关build 强度可量化对比。

### 第三期 · 世界探索感【已完成 v31】（关卡制里种出"开放世界"）
9. **兴趣点系统**（L）
   每关程序化撒 3-6 个可选兴趣点：宝箱舱（金币/装备）、精英哨站（重赏）、解谜节点（按序激活三座塔→开舱）、裂缝挑战（90s 清怪）。地图上用不同图标标出，收集度计入结算与成就。
10. **昼夜与天气循环**（M）
    每关 120s 昼夜过渡（雾色/光强 lerp 已有调色板基础）；"粒子风暴"天气：视野压缩+元素伤害+20%，复用铁雨/力场表现。
11. **剧情演出强化**（M）
    章节页升级：角色立绘（复用船长 Lathe 模型渲染快照）+ 打字机文本 + 简单分支（不影响数值，影响下一关台词与标记）。

**验收**：任意一关能玩出"我先去开宝箱还是直奔目标"的选择感；一次完整的昼夜+风暴体验。

### 第四期 · 打磨【已完成 v31】（低成本高感知）
12. **分层动态音乐**（M）：探索/战斗/巨兽三段程序化 loop 交叉淡入淡出。
13. **手柄支持**（S）：Gamepad API 映射左摇杆/ABXY/RT。
14. **照片模式**（S）：暂停+自由相机+滤镜（复用 postComp 参数）。

- 进度：第一期已完成（v30，check_p1 全过）；下一批：第二期养成与终局。

### 明确不做（与定位冲突）
- 多人联机/抽卡付费/无缝大世界加载——离线单文件定位不匹配。

## 四、节奏建议

- 第三期穿插做（每关兴趣点可以随新关卡自动获得）；
