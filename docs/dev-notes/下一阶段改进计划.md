# 《潮声之下》下一阶段改进计划（v38+）

> 基线：v37b，8820 行，18 个子系统全部在位。
> 方向：从"系统搭完了"进入"内容打磨 + 纵深加厚"阶段。
> 按玩家可感知收益排序，分三期，每期 3-4 项。

## 二、短板分析（按影响排序）

| # | 短板 | 现状 | 影响 |
|---|---|---|---|
| 1 | **怪物种类少** | 仅 7 基础型，攻击模式单一（追击/扑击/吐弹） | 100 关打下来怪都长一样 |
| 2 | **BOSS 机制雷同** | 阶段只改数值 + 弹幕环，招式差异不大 | 巨兽战缺乏"记忆点" |
| 3 | **天赋只是数值** | 天赋 Lv5 = +24% 伤害 / -16% CD，没有选择分支 | 养成策略浅 |
| 4 | **无引导** | 新玩家不知道元素反应/合成/深井的存在 | 前 30 分钟流失风险 |
| 5 | **地图空旷** | 生态装饰有碰撞但布局均匀，缺乏"地形叙事" | 探索感弱 |
| 6 | **音效种类少** | 攻击/受击/拾取/UI 共 ~10 种合成音 | 听觉疲劳 |
| 7 | **无难度选择** | 所有玩家同一难度曲线 | 高手嫌简单 / 新手嫌难 |
| 8 | **无周目/新鲜感** | 通关 100 关后没有"再来的理由" | 终局寿命短 |

## 三、改进计划（三期）

### 第一期 · 战斗纵深（让每关的战斗都不一样）

**1.1 精英变异词缀**（工作量 M）
- 精英怪随机获得 1 条视觉词缀（头顶图标+体色变化）：
  灼热（近身反弹伤害）/ 电壳（受击放电）/ 迅捷（移速 ×1.5）/ 荆棘（远程反弹）/ 虚影（受击概率闪避）/ 巨力（击退抗性+近战伤害 +50%）
- 实现点：`decorateMonsterFamily` 后追加词缀部件 + `tickMonsters` 词缀效果分支
- 验收：同一关卡打 3 只精英，3 种不同词缀；有词缀专属死亡特效

**1.2 BOSS 专属招式**（工作量 L）
- 每种 BOSS 加一个独有 3 阶段招式（当前只有弹幕环 + 震波）：
  - 蟹：横扫钳击（扇形 180°）+ 钳夹投掷（抛物线落点）+ 地底潜行突袭
  - 鳍母：召唤涡流（吸入拉扯）+ 音波尖啸（减速场）+ 跃出水面砸落
  - 水母：分身（3 个半透明幻影）+ 毒雾区（持续 DoT）+ 触手鞭击（扇形扫）
  - 航鲸：翻滚冲撞（直线冲刺）+ 深潜遁地（消失 3s 再冒出）+ 巨尾拍击
  - 荒凉之手：五指分离（五指各自射弹）+ 黑洞引力（吸引+DoT）+ 拍地全屏震
- 实现点：`tickBoss` 按 type 分支 + telegraph 预警圈复用
- 验收：每种 BOSS 至少 1 个"看见就知道是什么"的标志性招式

**1.3 难度选择**（工作量 S）
- 主页出征页加 3 档难度按钮：探索（怪物 -30% 生命伤害，金币 ×0.8）/ 标准 / 深渊（怪物 +30% 生命伤害，金币 ×1.3，掉落 +20%）
- 实现点：`MONSTER_BOOST` 桶外加难度系数乘入 `createConfiguredLevel`
- 验收：三档怪物血量可感知差异，掉落与金币倍率正确

**1.4 怪物攻击模式扩展**（工作量 M）
- 灰手：增加跳劈（跃起 0.5s → 落地 AOE）
- 刃鳍：增加二连扑（第一扑后 0.3s 反向二段）
- 墨鲛：增加三连弹（第三发速度 ×1.5 带预判）
- 实现点：各 tick 函数内随机/血量阶段触发新分支
- 验收：同种怪物出现至少 2 种攻击行为

### 第二期 · 养成与策略深度（让 build 有选择）

**2.1 天赋分支选择**（工作量 L）
- 每个天赋 Lv3 时二选一分岔（不能全选）：
  - 磁轨贯日：A=贯穿宽度 +50% / B=命中后附加 1s 减速
  - 震荡重锤：A=击退距离 ×2 / B=落地后留 3s 减速区域
  - 榴弹弹幕：A=弹数 +2 / B=榴弹爆炸范围 +50%
  - 相位撤离：A=冷却 -3s / B=落地后释放 1 次环形冲击
- 实现点：`ROLE_SKILLS` cast 函数按天赋分支走不同参数；养成页分岔按钮 UI
- 验收：同一技能不同分岔产生可感知的不同战斗效果

**2.2 遗章套装效果**（工作量 M）
- 同稀有度装备 3/5 件触发套装效果：
  - 3×史诗：全伤害 +8% / 5×史诗：技能冷却 -20%
  - 3×稀有：击杀回复 +3 / 5×稀有：移动速度 +10%
- 实现点：`applyEquipStats` 按装备遗章 rarity 计数
- 验收：凑齐套装时属性面板显示套装效果标签

**2.3 深井词缀扩展**（工作量 S）
- 新词缀：元素反噬（受到元素反应伤害 ×2）/ 磁力（子弹速度 -30%）/ 精英领主（每层多 1 只精英）/ 贫瘠（金币 -50%，遗章掉率 ×2）
- 实现点：`AFF` 数组追加 + 效果分支
- 验收：不同词缀层数策略不同

**2.4 周目标挑战**（工作量 M）
- 每周 3 个随机目标（如"用近战角色通关前 20 关""不用护幕通关深井 6 层""收集 30 个记忆碎片"），完成给大量结晶+专属遗章
- 实现点：周重置逻辑复用 DAILY_KEY 模式 + 目标检测钩子
- 验收：主页显示周目标进度；完成后领奖

### 第三期 · 体验打磨（看不见但摸得着）

**3.1 新手引导系统**（工作量 L）
- 首次进入 L1 时按步骤弹出指引箭头+文字：
  ① WASD 移动 → ② 左键攻击 → ③ Q 闪避 → ④ 1/2/3 技能 → ⑤ E 拾取 → ⑥ B 装备库 → ⑦ 元素反应提示 → ⑧ 传送门进入
- 实现点：meta.tutorialStep + 每步骤触发条件检测 + 箭头 UI
- 验收：新存档自动触发；老存档不弹；完成后不再出现

**3.2 小地图 POI 标记**（工作量 S）
- 宝箱/信标/裂缝/楼梯塔在小地图上显示彩色图标（当前只有怪物和裂隙）
- 实现点：`drawMinimap` 加 worldInteractives 遍历
- 验收：小地图上能看到金色宝箱点、蓝色信标点

**3.3 音效分层**（工作量 M）
- 每种武器独立命中音（脉冲=水晶碰撞 / 重锤=闷击 / 榴弹=爆炸）
- 巨兽招式预警音（每个 BOSS 独立）
- 步声（移动时周期播放底噪）
- 实现点：`sound()` 函数扩展音色参数 + 少量新合成器配置
- 验收：三武器听感可区分

**3.4 通关后周目（New Game+）**（工作量 M）
- 通关 100 关后解锁二周目：怪物全属性 ×1.5 + 随机词缀叠加 + 遗章掉率 ×2 + 专属称号
- 实现点：`meta.ngPlus` 计数 + `createConfiguredLevel` 属性乘区 + 主页"新周目"按钮
- 验收：二周目怪物明显变强；通关后回主页出现二周目入口

## 四、节奏与优先级

```
第一批（最快见效）：1.3 难度选择 → 3.2 小地图 POI → 1.1 精英词缀
第二批（核心深度）：1.2 BOSS 招式 → 2.1 天赋分岔 → 1.4 怪物攻击扩展
第三期（系统闭环）：2.2 套装效果 → 2.3 深井词缀 → 3.1 新手引导
第四期（长线）：    2.4 周目标 → 3.3 音效 → 3.4 周目
```
