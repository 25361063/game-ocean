# 潮声之下 · 星髓远征

第一人称**深海探索 / 多关卡闯关 / 局内构筑 / 巨兽战斗**小游戏，纯前端 HTML5 实现。

## 当前版本

- 主线入口：**`index.html`**（v58 触控战斗版）
- 自包含分发版：**`single-file.html`**（内联全部资源，可离线拷贝运行）
- 更新说明：见 `notes/`；完整历史见 [`../../docs/CHANGELOG.md`](../../docs/CHANGELOG.md)

## 玩法概要

- 20 关连续闯关（每 4 关一章，共五套生态），含证据回收、敌群清除、精英猎杀、限时生存、区域扫描、据点防守、混合调查、三波增援战等任务类型。
- 无尽深渊模式：清空波次后三选一构筑，波次强度与潮汐压力持续增长。
- 局内构筑、永久升级（船币）、成就系统、巨型 Boss 轮换。
- 桌面端 / 移动端完整适配，支持键盘焦点与触屏操作。

## 运行

用 Chrome / Edge 等现代浏览器打开 `index.html` 即可。游戏引擎与美术贴图均保存在仓库内，运行时不依赖网络。

## 联机

`tools/` 下提供局域网联机服务：

```bash
python tools/联机服务器.py
```

Windows 可直接运行 `tools/启动联机.bat`，或参考 `tools/允许局域网联机.ps1` 放行防火墙。
