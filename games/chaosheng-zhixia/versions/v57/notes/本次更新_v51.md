# v51 海草、鱼骨与地形衔接

从 v50 独立复制，旧版本不覆盖；原游戏入口与联机启动器保留。

## 改动

- 海草由圆锥改成有曲率、宽度变化和尖端的双面叶片；三种株形/配色，成簇生长，根部固定、上部随水流摆动。
- 大型海带障碍使用多片宽叶；每片叶子的根部单独采样地面，包括缩放、旋转后的实例。
- 巨型鱼骨拱廊改为七组肋骨、连续脊椎、椎节、头骨与下颌。小型骨骸也使用成套骨架，不再是单根短柱。
- 巨骨每只支脚独立适配坡地，碰撞从旧的中央圆柱改为支脚碰撞，骨廊中央可以穿行。
- 地标建筑按底座周围的最高地面定位，再生成贴地基础；维护舱、货箱、沉船段、实心攀爬柱增加沿地形向下延伸的基础封边。原攀爬顶面不变。
- 散落金属舱板按顶点贴合坡面。悬浮平台仍有意悬空。

建筑基础采用水平上沿和随地形变化的下沿，并非强制让整栋建筑随斜坡倾斜。极端地形下基础侧墙可能较高，这是承台而不是悬空。
