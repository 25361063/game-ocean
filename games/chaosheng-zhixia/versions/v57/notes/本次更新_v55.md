# v55 塔上射击与单发瞄准镜

独立复制自 v54，保留旧版。游戏入口仍为「潮声之下_深渊潜航3D_v22.html」。

- 修复塔上开火被“高于地形即下坠攻击”截获的问题。远程角色在塔顶、阶梯及空中可正常射击；下坠攻击仅用于真正滞空的近战角色。
- 限制自动处决的高度差，避免射击时误处决楼下目标。
- 远程角色鼠标右键切换瞄准镜；32° 视野、中心十字线，瞄准时降低转向灵敏度。第三人称开镜临时使用第一人称观察，退镜恢复原视角。
- 瞄准射击只生成一颗弹丸，弹丸伤害乘 5；分裂弹匣在本次瞄准射击不额外分裂，其他弹丸装备属性保留。
- 成功开火后自动退出；冷却中或空弹不会误退镜。右键可主动取消。暂停、失焦、切枪、重新开始时清理瞄准状态。
- 开镜射击按普通单发结算，不再叠加蓄力射击流程。
