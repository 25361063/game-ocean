# v57 手机横屏界面

基于本地最新 v56 复制为新版本，未覆盖旧版。游戏入口沿用 `潮声之下_深渊潜航3D_v22.html`，需保留整个 assets 文件夹。

## 横屏布局

- 左手移动，右手战斗；主射击 72px、闪避 56px、技能/上浮/瞄准 48px，顶部辅助按钮 44px。保留屏幕安全区域。
- 战况、装备明细、构筑与视角等辅助功能集中在“更多”抽屉，默认收起；展开时隐藏其下方战斗键，减少误触。
- 小地图点击展开/收起；任务摘要点击展开详情。去掉重复技能栏，让战斗画面更通透。
- 增加手机瞄准键，沿用远程武器单发五倍伤害、射击后自动取消瞄准的机制。
- 开始页缩小海报标题区，优先显示角色；模式和联机说明折叠，开始按钮固定在底部。
- 竖屏显示旋转提示；战斗中旋转为竖屏会暂停，横屏后点击“继续下潜”。“进入横屏”会在浏览器允许时申请全屏与横屏锁定，不支持时需手动旋转。
- 修复原有装备库“返回战场”按钮未绑定动作的问题。
- 保留 v56 的后处理优化：只对场景目标开启多重采样，Bloom 中间缓冲不做重复抗锯齿。

## 验证

Chrome 触屏模拟检查 844×390、740×360、667×375、932×430：9 个主要操作键均在视口内，触摸区域不小于 44px、彼此不重叠；实测点击开始、更多、装备库及退出、瞄准和单发退出、地图展开、暂停与恢复。393×852 验证旋转提示与自动暂停。测试文件 `test_mobile57.cjs`。

测试是浏览器触屏模拟，不代表已在实体 Android/iPhone 上验证；系统横屏锁定与浏览器全屏支持取决于设备。

手机访问：电脑运行本目录的 `启动联机.bat`，手机与电脑连接同一 WiFi，打开窗口显示的地址，然后横放手机。不要只单独发送 HTML 而漏掉资源文件夹。
