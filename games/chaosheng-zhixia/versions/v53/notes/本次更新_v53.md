# v53 局内装备实效重构

独立复制自 v52，保留旧版。入口仍为「潮声之下_深渊潜航3D_v22.html」。

## 战斗与装备

- 分裂弹匣改成一次开火生成两发独立弹丸，共用一次开火消耗与冷却；支持蓄力，独立碰撞列表和生命周期。
- 蓄力弹接入贯穿、制导、元素、震荡与范围增益，并受攻击冷却装备影响。
- 回响核心接入实际近战半径/弹丸爆裂；震荡弹头对原生爆炸武器额外增加半径。
- 修复基础暴击率被重复叠加：无装备 12%，加聚焦镜片后 20%（无其他养成加成）。
- 满栏合成先计算被消耗材料腾出的槽位；元素注入器与阴阳弹匣互斥，购买前提示；近战角色不再能购买无效弹道模块。
- 工程路线护幕技能冷却接入护幕装备倍率。

## 看得到的效果

- 左侧可折叠「装备实效」面板：伤害、生命、移速、间隔、暴击、韧伤、弹数、半径、击杀回复、金币、护幕与超频数值。
- 显示最近实际命中伤害、击杀总回复与金币加成记录；总回复包含本局其他回复来源，不冒充装备独占收益。
- 武器随装备槽数增加发光模块；元素弹变色，贯穿/制导/爆裂弹增加不同色环标识。

## 验证

Chrome 实机自动化：36 件装备数值有限性、12%/20% 暴击、满栏合成、元素冲突、金币不足、近战兼容限制、双发携带贯穿/制导/霜/范围、弹丸清理，均通过；未捕获运行异常。
继承场景回归：多个章节场景加载、两种远程角色开火和清理，通过。
测试脚本：test_equipment53.cjs；截图：装备实效_v53.png。

以上不是所有关卡的人工通关，也不代表每一种元素反应组合已穷举测试。
