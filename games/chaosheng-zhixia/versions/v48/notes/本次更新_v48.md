# v48 人物重制与开始界面

独立复制 v47 修改，旧版本未覆盖。双击本目录的游戏 HTML 可单机游玩，联机仍使用“启动联机.bat”。HTML 保留原内部文件名，避免破坏服务器入口。

## 本次内容

- 三位船长改为露面、长外套、常规鞋靴造型，移除新版模型的潜水头盔、氧气罐和脚蹼；第一人称手部改为肤色。
- 独立肤色、发型、衣料配色，增加眼睛、眉毛、手指、翻领、纽扣、衣缝和职业饰件。模型为程序化风格化人物，并非海报同等精度的写实扫描模型。
- 角色选择增加三幅人物海报，支持选中状态、键盘操作与手机布局。
- 开始界面改为暗青航务终端：人物横幅、暖金标题与按钮、固定导航、全宽模式卡。横幅“准备下潜”可定位到原有开始按钮，不绕过原有选择流程。
- 沿用 v47 怪物编队及联机逻辑。

## 验证

运行 test_captains48.cjs、test_characters.cjs、test_squad47.cjs：三角色进入游戏、海报加载、桌面无横向溢出、人物包围盒/面数、朝向/落脚/联机插值、编队阵位和单怪回退通过。截图人工检查桌面、390px 手机角色页和人物预览。不是全关通关测试。
