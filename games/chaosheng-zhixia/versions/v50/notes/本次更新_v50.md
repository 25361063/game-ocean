# v50 场景建筑与装饰重制

独立复制 v49 修改，保留旧版和 Vitruvian 角色。游戏入口仍为“潮声之下_深渊潜航3D_v22.html”，以兼容联机启动器。

## 本次改动

- 地标重做为古舰工业设施：分层基座、装甲壳体、承重肋、维护面板、输能管线、铭牌和顶部组件。五章使用不同配色，高度和顶部结构有差异。
- 约五分之一非海带障碍改为半埋式维护舱，沿用原障碍的位置、碰撞半径与顶面高度。
- 可攀爬柱、浮台和阶梯增加结构环、舱板与边缘灯；不改原跳跃/攀爬规则。
- 跑图货箱与宝箱增加倒角箱壳、加固条、锁扣、编号；沉船块体增加舱壁肋、凹面板和外露管道。
- 记忆节点增加档案终端底座，保留原剧情交互与悬浮文本板。
- 材质使用本地程序化磨损纹理；未引入运行时外部图片依赖。

不是所有生态物件都已重做：海草、部分珊瑚、粒子与热泉主体沿用旧版。
