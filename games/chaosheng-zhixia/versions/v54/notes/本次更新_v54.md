# v54 攀塔修复与重建

独立复制 v53，保留旧版；入口仍是「潮声之下_深渊潜航3D_v22.html」。

## 修复与功能

- 修复旧模型与楼梯支撑面的角度轴相反、塔顶相对高度/世界高度混用问题。
- 重建 80 级宽螺旋梯、接地入口坡道、桩基础、金属塔芯、发光扶手、顶层平台与中继台。模型踏步和支撑面共用尺寸；连续支撑消除上楼卡阶。
- 塔顶平台与楼梯分开定义，避免下楼时被整块隐形顶板托住。
- 选址避让障碍物，并检查入口坡度及埋地情况；后生成的立体装饰避让塔区。
- 普通人物行走即可登顶和下楼；靠近入口有提示，首次抵达中继台获得本塔 120 金币与 2 发弹药（仍受弹药上限限制）。
- 怪物通过入口、螺旋阶梯和平台路线追击，也能下塔；沿阶梯时暂时由塔区导航接管，抵达平台后恢复原 AI。
- 怪物模型、远程射击起点跟随楼梯高度；不同楼层不再水平互相推挤。玩家弹丸和近战命中加入怪物高度校验。
- 静态塔体按材质合并为 4 个网格，避免每级台阶、每段扶手单独提交绘制。

- 怪物从塔外四个方向寻找入口并登塔通过。
- 六只混合怪物测试中均抵达过塔顶高度。
