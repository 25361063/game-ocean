潮声之下 · 深渊潜航 —— 手机版（Android）使用说明
================================================

一、安装
-------
1. 把 潮声之下_手机版_1.0.0.apk 拷进手机，用文件管理器点它安装；
   若提示"不允许安装未知来源应用"，在系统设置里允许文件管理器/浏览器的安装权限即可。
   也可以用数据线：adb install -r 潮声之下_手机版_1.0.0.apk
2. 首次启动会弹一段操作提示，看完即可开始。之后不再出现。
3. 要求：Android 7.0 及以上；建议横屏握持并关闭系统"自动旋转锁定"。

二、操作（横屏）
---------------
· 左手边任意位置按下并拖动 = 移动（摇杆会在你按下的地方出现，不挡视线）
· 右手边任意位置拖动       = 转视角
· 右下角大按钮             = 普攻（最贴近右下角，拇指自然落点）
· 右下角同行左侧           = 下潜
· 右下角其它键             = 跳跃 / 切武器 / 闪避（依次向左上）
· 右上角 (2×2 或竖排)      = 髓瓷护幕 / 神经超频 / 切换视角 / 装备库
· 右上角最边上             = 暂停
· 屏幕下方中间             = 拾取（有掉落物时才出现）
· 手机返回键               = 打开菜单：继续游戏 / 连接主机 / 重新载入 / 退出

刘海屏、圆角屏会自动把按键让开安全区；16:9 的小屏机型会把右上角四个技能键
自动改成 2×2 方阵，避免和顶部状态栏、右下普攻挤在一起。

三、存档
-------
存档自动保存在手机应用数据里，升级安装（同签名覆盖）不会丢。
想彻底清空：系统设置 → 应用 → 潮声之下 → 存储 → 清除数据。

四、联机（手机作为"客机"）
-------------------------
手机版本身不能当联机主机，需要一台电脑跑主机：
1. 电脑打开 潮声之下 桌面版（或运行 启动联机.bat），保持开启；
2. 电脑上查看地址：桌面版菜单「联机 → 服务器与局域网地址…」，记下形如
   192.168.1.20:8123 的局域网地址；
3. 手机按返回键 → 菜单 → 「连接主机（联机）…」→ 填上面的地址 → 连接；
4. 之后手机上的画面就是电脑那份游戏，两端输入相同房间号即可一起下潜（最多 2 人）；
5. 想回单机：返回键 → 菜单 → 「回到单机」。

连不上时按顺序查：两台设备是否在同一网络 → 电脑是否允许了防火墙 → 地址端口是否为 8123
→ 电脑端窗口是否还开着。手机与电脑可以在浏览器里打开 http://电脑IP:8123/diagnostics 自测。

五、常见问题
-----------
1) 进游戏要等几秒
   首次启动要把 52MB 的人物模型数据交给内置网页引擎，属正常（一般 3—8 秒）。
2) 画面卡 / 发烫
   这是 3D 游戏，长时间玩建议降一档画质相关设置或暂停休息；低配机型建议关闭后台应用。
3) 触控按键位置不合适（折叠屏、超宽屏）
   用工程里的 npm run check:layout 可查看 8 种机型的键位检查报告，
   并在 mobile/scripts/sync-mobile.mjs 的补丁 CSS 里微调后重新打包。
4) 被杀毒软件/手机管家拦截
   安装包未做签名证书（用的是调试签名），部分手机管家会提示"未知来源"。
   确认来源可靠后选择"继续安装"即可；正式上架需换成正式签名证书。
5) 想改游戏数值或换图
   改工作区里的游戏文件后，执行 npm run sync 再 npm run build:apk 重新打包。
