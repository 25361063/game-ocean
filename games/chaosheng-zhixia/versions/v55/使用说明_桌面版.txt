潮声之下 · 深渊潜航 —— 桌面版使用说明
=====================================

一、启动
-------
1. 安装版：双击桌面「潮声之下」快捷方式（或用安装向导结束时勾选的启动）。
   免安装版：解压后直接双击「潮声之下.exe」。
2. 不需安装浏览器、不需要 Python、不需要运行任何 .bat 脚本。
   程序启动时会显示一张启动画面，随后自动进入游戏主界面（首次约 5—15 秒，与硬盘速度有关）。
3. 首次运行若 Windows 防火墙弹窗询问，请勾选「专用网络」并允许 —— 这是局域网联机需要的。

二、菜单与快捷键
---------------
【游戏】重新载入页面(F5) · 全屏切换(F11) · 显示/隐藏菜单栏(Alt+M) · 退出(Alt+F4)
【联机】服务器与局域网地址… · 复制局域网地址 · 打开联机诊断页 ·
        作为客机连接主机… · 返回本地单机模式 · 重启联机服务
【存档】打开存档目录 · 导出存档… · 导入存档… · 清除本机存档…
【视图】缩放 100%/125%/150%/85% · 开发者工具(F12) · 打开日志目录
【帮助】本说明 · 打开游戏文件目录 · 关于桌面版

游戏自身按键（WASD 移动、空格、E、Esc、M 小地图等）保持与网页版完全一致，桌面版不做任何拦截。

三、联机（本程序自带联机服务，开箱即用）
---------------------------------------
打开菜单「联机 → 服务器与局域网地址…」，会看到类似：
    本机地址：http://127.0.0.1:8123
    局域网地址：http://192.168.1.20:8123（WLAN）
三种玩法：
  A. 两台电脑都装桌面版：主机看上面的局域网地址；另一台按
     「联机 → 作为客机连接主机…」填 192.168.1.20:8123，连上后两端输入相同房间号。
  B. 另一端用手机/浏览器：打开 http://192.168.1.20:8123 输入房间号即可（最多 2 人）。
  C. 另一端仍是网页版：让对方按老办法运行 启动联机.bat，你这边用
     「作为客机连接主机…」填他那台机器的地址。

连不上时按顺序查：两人是否在同一网络 → 主机是否允许了防火墙 → 地址端口是否为 8123 →
菜单「联机 → 打开联机诊断页」看是 HTTP 还是 WebSocket 这一步失败。

四、存档
-------
存档保存在 %APPDATA%\潮声之下\ 目录（菜单「存档 → 打开存档目录」可直接跳转）。
换电脑或重装前，用「导出存档…」存成 JSON，之后「导入存档…」即可恢复。
卸载程序默认不删除存档；确实要清空请用「清除本机存档…」（有二次确认）。
注意：以「客机」身份连到别人主机时，用的是那台主机来源下的存档，与本地单机存档互相独立。

五、被杀毒软件拦截 / 文件被删除怎么办
-----------------------------------
本程序没有购买代码签名证书，部分杀软（卡巴斯基、360、火绒、电脑管家、Defender）
可能把安装包或主程序当成可疑文件删掉 —— 这属于误报，不是文件有问题。

最省事的做法（按顺序）：
1. 先加排除项，再解压/安装（顺序反了会在解压瞬间被删）：
   · 卡巴斯基：设置 → 安全威胁与排除项 → 排除项 → 添加"文件或文件夹"；
     已被隔离的到「更多工具 → 隔离区」恢复并"添加到排除项"。
   · Windows Defender：设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 →
     排除项 → 添加文件夹。
   · 360 / 火绒 / 电脑管家：在"信任区/信任列表"里添加安装包与解压目录；
     被拦的到"恢复区"恢复并勾选信任。
2. 优先用**免安装 zip 版**：解压后直接双击「潮声之下.exe」运行。
   zip 比"安装包.exe"少一层自解压外壳，被误删的概率低得多。
3. 核对文件是否被替换：发布包里附有 SHA256SUMS.txt，
   PowerShell 执行 Get-FileHash .\潮声之下_1.0.0_x64.zip -Algorithm SHA256 对照即可。

如果确认是误报，也可以去厂商的误报申诉入口提交（一般 1—3 天处理）：
卡巴斯基 opentip.kaspersky.com、微软 wdsi filesubmission、360 open.soft.360.cn。

六、常见问题
-----------
1) 卡在启动画面 / 白屏
   菜单「视图 → 打开日志目录」看 logs/main.log；也可以在游戏里按 F12 看 Console 报错。
2) 提示端口 8123 被占用
   常见于本机还开着 Python 联机服务器。程序会自动退回本机模式，单机照玩；
   关掉占用程序后，用「联机 → 重启联机服务」即可恢复局域网联机。
3) 帧率低、画面卡
   确认独显是否被使用（笔记本插电、电源模式高性能、显卡控制面板里为该程序指定独显）。
   显卡驱动异常时可在命令行加参数启动：潮声之下.exe --disable-gpu（走软件渲染，能玩但帧率低）。
4) 想临时改游戏数值或换图
   菜单「帮助 → 打开游戏文件目录」，里面的 HTML 与 assets 就是游戏本体，改完重启程序即可，
   不需要重新打包。
5) 卸载
   设置 → 应用 → 潮声之下 → 卸载；或用安装目录里的 uninstall 程序。
