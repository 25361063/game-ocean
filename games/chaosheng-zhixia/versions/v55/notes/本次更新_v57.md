# 本次更新 · v57 —— 手机版（Android APK）

更新时间：2026-09-16
类型：交付/工程化（游戏玩法逻辑未改，只做移动端适配与打包）

## 一句话

在 `mobile/` 里把同一份网页游戏封装成 **Android 安装包**（`dist/潮声之下_手机版_1.0.0.apk`，32 MB，
Android 7.0+，横屏），并**用实测数据重排了触控键位**。不需要 Android Studio / Gradle，一条命令出包。

## 架构（与桌面版同一思路）

```
MainActivity（横屏 sensorLandscape + 沉浸全屏 + 屏幕常亮）
  └─ AssetServer：127.0.0.1:19123 提供 assets/www（http）
       └─ WebView 加载 http://127.0.0.1:19123/
```

固定端口是关键：WebView 的 localStorage 按 origin 隔离，端口一变存档就丢。
不用 `file://` 的原因与桌面版一致（相对路径资源、`netConnect()` 要求 http/https、localStorage 行为）。

联机策略：**手机当客机**。返回键 → 菜单 → 「连接主机（联机）…」填桌面版显示的 `192.168.x.x:8123`；
玩家在单机模式点游戏内联机入口时，`AssetServer` 会捕获 `/health` 请求并弹原生引导。

## 键位分布（本次重点，全部按实测修正）

用 `npm run check:layout`（Electron + 触屏伪装 + 真实开一局）在 **8 种机型横屏尺寸**下量取，
发现并修正了 3 个真问题：

| 问题 | 实测 | 修正 |
| --- | --- | --- |
| 下潜键 × 切武器键重叠 | 36×36 px 重叠 | 下潜移到 `right:150,bottom:12`（与普攻同一水平行），尺寸固定 48×48 |
| 右上技能列被顶部 HUD 压住 | 游戏中 HUD 实际高 **95px**，护幕键从 `top:64` 起 | 竖列整体下移到 `104 / 152 / 200 / 248` |
| 矮屏（≤430px 高）排不下 | HUD95 + 竖列192 + 普攻76 > 360 | 矮屏自动改 **2×2 方阵**（`top:104/154`，`right:10/62`） |

修正后 20:9 机型（874×394 视口）实测坐标：

```
普攻 64×64 距右12 距底12    下潜 48×48 距右150 距底12
跳跃 52×52 距右80 距底80    切武器 48×48 距右150 距底72
闪避 50×50 距右146 距底140  拾取 88×44 居中距底12
护幕/超频/视角/装备库 46×46（矮屏 2×2，高屏竖列，距右 10/62）
暂停 44×44 右上角
```

- 左手区是**动态摇杆**（按下才出现底座），不挡视线；左下角另有武器槽与技能条；
- 全部按键 ≥44px，且定位都带 `env(safe-area-inset-*)` + 补丁注入的 `viewport-fit=cover`，
  刘海/圆角屏自动让开（静态检查 10 条规则 0 问题）；
- **当前结果：8 种尺寸 0 项问题**（`mobile/layout-check/layout-report.json`），
  截图：`手机版键位_v57.png`（20:9）、`手机版键位_16比9_v57.png`。

## 构建命令

```bash
cd mobile
npm run fetch-toolchain      # 首次：约 315MB（国内镜像优先）
npm run sync                 # 游戏资产 + 移动补丁
npm run check:layout         # 8 机型键位校验（无独显加 TIDE_SOFTWARE_GL=1）
npm run build:apk            # → dist/潮声之下_手机版_1.0.0.apk
```

## 新踩的坑（已写进 mobile/README.md）

1. **aapt2/javac 不支持含中文的路径** → 构建脚本自动把内容搬到 ASCII 临时目录再编译（`TIDE_BUILD_STAGE` 可改）；
2. 新版 Node **禁止直接 spawn `.bat/.cmd`** → 改为 `java -cp d8.jar` / `java -jar apksigner.jar`；
3. 本环境安全外壳会把 `fs.rmSync` 转成回收站操作，**大目录会卡死** → 自实现 `removeDir()`；
4. 7za 输出管道没人读、条目过万时**死锁**（platform 包含 1 万多个文件）→ `stdio: 'ignore'`；
5. 7-Zip 列表用反斜杠显示路径 → 资产校验正则要正反斜杠都认（否则误报"未找到 assets"）。
