# v49：Vitruvian 人物与海报配色服装

在 v48 的独立副本修改，旧版本保留。单机双击“潮声之下_深渊潜航3D_v22.html”，按 V 切换第三人称；“Vitruvian人物预览.html”查看三套服装。保留旧 HTML 内部文件名是为兼容联机启动器。

## 已实现

- 使用 Vitruvian 实际人体、面部、头发、骨骼和衣服网格，替换 v48 拼装人物。重配 Three.js 皮肤/眼睛/头发材质，贴图最长边缩至 1024。
- 三套原创建模外衣参考现有海报：青绿调查长外套、象牙白工程长制服、酒红皮质长外套。包含长袖、翻领、立领、腰带、纽扣、徽章、滚边与开衩衣摆，挂接导入骨骼。
- 基础行走摆臂、腿部与衣摆动作采用原创程序化控制；没有使用上游 Mixamo 动画。
- 角色图包和模型数据本地打包，不需要运行时联网；直接打开本地 HTML 也能加载，不依赖 file:// 的跨源 GLB 请求。
- 保留角色选择海报、开始界面、原战斗和编队系统。

## 当前边界

三人共用 Vitruvian 基础脸型，服装为参考海报的游戏化改造，并非海报人物的完整写实复刻。发型、年龄、男性面部和体型仍需进一步独立定制。不是 Godot 原皮肤着色器的等效移植；没有布料物理。极端动作下衣物穿插仍可能发生。

单角色约 43 万三角面（含隐藏的上游眼部网格），几何体主要开销是头发和原始衣服。已做贴图与无用形变/动画数据整理，但尚未完成低端手机 LOD，不能宣称移动端稳定高帧率。

test_captains48.cjs（继承文件名，已增加 v49 检查）通过：本地图片加载、三角色进入游戏、开始按钮定位、桌面/手机角色页截图、120 步转向/骨骼更新矩阵有限值、实际蒙皮网格存在、第三人称渲染；浏览器未捕获运行异常。
test_squad47.cjs：编队角色槽、侧翼、后排、攻击锁、减员和单怪回退通过。
